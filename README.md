## 🛠️ Coding Approach

| Step | What I Do |
| ---- | --------- |
| 1️⃣ | Understand the problem |
| 2️⃣ | Identify inputs and outputs |
| 3️⃣ | Develop the logic |
| 4️⃣ | Implement the solution |
| 5️⃣ | Test with different inputs |
| 6️⃣ | Analyze edge cases |
| 7️⃣ | Improve the solution |
| 8️⃣ | Commit progress to GitHub |

## ⏱️ Complexity Quick Reference

Future solutions will include time and space complexity where possible.

| Complexity | Name | Example |
| ---------- | ---- | ------- |
| O(1) | Constant | Accessing an array element |
| O(log n) | Logarithmic | Binary search |
| O(n) | Linear | Traversing an array |
| O(n log n) | Linearithmic | Merge sort |
| O(n²) | Quadratic | Nested loops, selection sort |
| O(2ⁿ) | Exponential | Naive recursive Fibonacci |
